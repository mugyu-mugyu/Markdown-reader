# 更新日志

记录墨页各版本的功能变化。

## v1.2.0

### 新增

- 多文档标签页及一次选择多个文件的打开方式，同一路径复用已有标签。
- 每篇文档独立保留内容、未保存标记、撤销记录、光标选择和滚动位置。
- 标签和临时文件的关闭按钮，以及临时工作区的右键关闭菜单。
- `Ctrl + W` 关闭文档，`Ctrl + Tab` / `Ctrl + Shift + Tab` 切换标签。
- 关闭全部标签后的起始页。

### 改进与修复

- 浅色、深色主题下文字选中背景与当前行背景明显区分。
- 关闭文档时按文件名询问保存，关闭窗口时检查全部标签页。
- 批量关闭临时工作区时，取消操作会保留整组文档。
- 另存为目标已在其他标签页打开时提供保护提示。
- 关闭临时文档同步移除侧边栏条目；关闭全部文档清除最近文档记录。

### 安装包

- Windows 10 / 11 x64：`Moye-Setup-1.2.0.exe`，附带卸载程序。
- 关闭旧版本后运行新安装包升级，保留工作区文档与设置。

## v1.1.0

### 新增

- 新增图片插入窗口，支持工具栏「图片」按钮及 `Ctrl + Shift + I` 快捷键。
- 支持选择本地图片或插入 HTTP / HTTPS 图片链接，提供缩略图预览、图片描述和图注输入。
- 本地图片导入到文档旁的 `assets` 文件夹，以相对路径引用；重复导入相同图片复用附件。
- 另存为到其他目录时，同步复制应用导入的图片附件。
- 独立成段的 Markdown 图片标题可渲染为图片下方的图注。
- 图片链接支持查询参数和不含图片扩展名的地址，并提供加载失败反馈。

### 改进与修复

- 阅读模式中插入图片时自动恢复编辑区。
- 修正图片描述中方括号等转义符号的显示，完善图注特殊字符处理。
- 未保存的新文档插入本地图片时，先选择文档保存位置。

### 安装包

- Windows 10 / 11 x64：`Moye-Setup-1.1.0.exe`，附带卸载程序。
- 关闭旧版本后运行新安装包升级，保留工作区文档与设置。

## v1.0.0

首个正式版本。

### 新增

- Markdown 文档新建、打开、保存、另存为及常用快捷键。
- 在设置中选择本地文件夹作为工作区，使用侧边栏浏览文档，在磁盘上创建文件夹和 `.md` 文件。
- 文件树目录变化监测与手动刷新。
- 工作区外打开的文档显示在「临时工作区」中，保存写回原位置；重启恢复最后打开的文档。
- Markdown 编辑与实时预览双栏布局，可拖动分隔条调整宽度。
- 隐藏编辑区后预览自动居中，侧边栏支持单独隐藏。
- 常用 Markdown、表格、任务列表、脚注、链接及手写 Markdown 图片语法渲染。
- 代码高亮与复制、GitHub 风格提示块、KaTeX 数学公式、Mermaid 图表。
- 浅色、深色、跟随系统主题和预览字体大小设置。
- 未保存修改提示、外部文件修改检测，以及保留原编码和换行方式的文件保存。
- Windows 安装向导、安装目录选择、桌面与开始菜单快捷方式、卸载程序。

### 安装包

- Windows 10 / 11 x64：`Moye-Setup-1.0.0.exe`。
- 无需额外安装 Node.js；卸载保留工作区文档与应用偏好设置。
